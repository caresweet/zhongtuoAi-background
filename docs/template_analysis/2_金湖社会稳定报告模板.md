## 1 拟征收决策基本概况

### 1.1 决策名称
- 类型：**换数（只替换数据位）**
- 换什么：项目/决策名称、建设内容
- 从哪取：立项批复、用地预审/规划许可等批文

### 1.2 决策单位
- 类型：**换数（只替换数据位）**
- 换什么：单位名称、法人、联系方式
- 从哪取：项目批复文件 / 建设单位提供
- 数据位：建设单位

### 1.3 拟征地位置
- 类型：**换数（只替换数据位）**
- 换什么：位置描述、四至、所属行政区
- 从哪取：勘测定界报告 / 征地红线图

### 1.4 征收范围、面积及地上附着物情况
- 类型：**换数（只替换数据位）**
- 换什么：征收范围、面积、地类构成
- 从哪取：勘测定界报告（面积一律以勘界为准）
- 口径/公式：各地类面积合计 = 征收总面积；表与正文同口径

### 1.5 资金筹措
- 类型：**换数（只替换数据位）**
- 换什么：总投资、资金来源与落实方式
- 从哪取：可研/立项批复 / 建设单位提供

### 1.6 决策实施周期
- 类型：**换数（只替换数据位）**
- 换什么：起止时间、阶段安排
- 从哪取：施工组织设计 / 建设单位提供日期

### 1.7 决策征地红线图
- 类型：**换数（只替换数据位）**
- 换什么：图件与图号
- 从哪取：勘测定界报告附图 / 征地红线图

# DB32/T4013-2021 第三方社会稳定风险评估规范

> **【技术标准/江苏省/2021/全文/风险等级判定、四维分析、量化评分】**

## 一、适用范围

本文件规定了第三方机构开展重大决策社会稳定风险评估（以下简称"稳评"）的基本要求、评估程序、评估方法、评估内容和评估报告编制要求。

本文件适用于江苏省行政区域内重大决策事项的社会稳定风险评估工作，包括但不限于土地征收、重大工程建设、重大政策制定等。

## 二、评估程序

### 2.1 评估准备
- 成立评估工作组，明确职责分工
- 收集决策事项相关资料
- 制定评估工作方案

### 2.2 风险调查
- 实地调查：拟征地区域自然环境、社会环境、经济状况
- 公众参与：问卷调查、座谈会、听证会、入户走访
- 利益相关者分析：识别直接和间接受影响的群体
- 媒体舆情分析：收集网络舆情、媒体报道

### 2.3 风险识别
采用检查表法、专家调查法、头脑风暴法等方法，从合法性、合理性、可行性、可控性四个维度识别风险因素。

### 2.4 风险分析
- 定性分析：分析风险因素产生的原因、发生概率、影响程度
- 定量分析：采用量化评分法，对每个风险因素进行赋值打分

### 2.5 风险等级判定
根据量化评分结果，将风险等级划分为：
- **低风险**（A级）：综合评分≥16分，可以实施
- **中风险**（B级）：综合评分12-16分，需采取风险防范措施后实施
- **高风险**（C级）：综合评分<12分，暂缓实施或不予实施

## 三、评估内容（四维分析）

### 3.1 合法性分析
评估决策事项是否符合以下要求：
1. 决策主体具有法定权限
2. 决策目的符合公共利益需要
3. 决策内容符合相关法律法规和政策规定
4. 决策程序符合法定程序要求

主要法律依据：《中华人民共和国土地管理法》《中华人民共和国城乡规划法》《国有土地上房屋征收与补偿条例》《中华人民共和国行政许可法》

### 3.2 合理性分析
评估决策事项是否符合以下要求：
1. 符合经济社会发展规划
2. 符合大多数群众的利益诉求
3. 兼顾了不同利益群体的合理关切
4. 补偿标准合理、公平

### 3.3 可行性分析
评估决策事项是否具备以下条件：
1. 符合当地经济社会发展水平
2. 资金保障充足、来源合法
3. 实施条件成熟、时机恰当
4. 群众支持配合度高

### 3.4 可控性分析
评估决策事项是否存在以下风险：
1. 可能引发群体性事件的概率和程度
2. 可能引发个人极端行为的概率和程度
3. 可能引发网络舆情的概率和程度
4. 现有防范化解措施的有效性

## 四、量化评分指标体系

### 4.1 合法性指标（共8项，满分16分，每项2分）
1. 决策主体资格合法合规
2. 决策依据充分、合法
3. 符合国民经济和社会发展规划
4. 符合城乡规划
5. 符合土地利用总体规划
6. 符合相关行业发展规划
7. 公众参与程序符合规定
8. 群众对项目的认知度

### 4.2 合理性指标（共3项，满分6分，每项2分）
1. 项目选址合理
2. 补偿标准合理
3. 群众对补偿方案的满意度

### 4.3 可行性指标（共5项，满分10分，每项2分）
1. 资金筹措到位
2. 施工条件具备
3. 配套设施完善
4. 群众支持配合度
5. 社会稳定基础良好

### 4.4 可控性指标（共6项，满分12分，每项2分）
1. 社会矛盾纠纷排查化解情况
2. 社会治安状况
3. 公共参与程度
4. 宣传解释工作覆盖度
5. 舆情风险应对能力
6. 应急预案完善程度

### 4.5 综合评分计算
- 综合得分 = Σ(各指标得分)
- 满分 = 16 + 6 + 10 + 12 = 44分（措施前）

## 五、风险防范化解措施

### 5.1 风险防范措施
1. 加强政策宣传解释，提高群众知晓度
2. 严格规范征收程序，确保公开透明
3. 合理确定补偿标准，保障群众合法权益
4. 做好信访接待工作，及时回应群众诉求

### 5.2 风险化解措施
1. 建立矛盾纠纷调解机制
2. 完善应急预案，做好舆情管控
3. 加强社会治安防控
4. 落实安置保障措施

### 5.3 应急预案
1. 成立应急指挥机构
2. 制定分级响应机制
3. 开展应急演练
4. 储备应急物资和力量

## 六、评估报告编制要求

### 6.1 报告结构
社会稳定风险评估报告一般包括以下章节：
1. 拟征收决策基本概况
2. 评估过程、方法和依据
3. 社会稳定风险因素调查
4. 决策综合分析（合法性/合理性/可行性/可控性）
5. 风险因素识别与初始等级表
6. 措施前风险等级研判
7. 风险防范与化解措施
8. 措施后风险等级评估
9. 评估结论与建议
10. 应急预案

### 6.2 格式要求
- 正文：仿宋_GB2312，四号字
- 一级标题：黑体，小三号字
- 二级标题：黑体，四号字
- 三级标题：楷体_GB2312，四号字
- 表格：宋体，五号字

### 6.3 术语规范
- 使用"社会稳定风险评估"，不得简称"稳评"（除标题和表头外）
- 使用"拟征收土地"，不得使用"征地"
- 法律名称使用全称，不得简写
- 量化数据保留一位小数

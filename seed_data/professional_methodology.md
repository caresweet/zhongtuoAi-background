# 社会稳定风险评估专业方法论 — 综合实务书籍精华

> **【理论文献/全国/学术著作/五要素模型至评估程序/风险定级方法、方法论**

## 一、五要素菱形评估模型（唐钧《社会稳定风险评估与管理》）
核心理念：评估目标为"反对最小化和满意最大化"

### 五要素
| 要素 | 说明 |
|------|------|
| 意愿度 | 民众对项目的意愿倾向 |
| 支持度 | 民众对项目的支持程度 |
| 反对度 | 民众对项目的反对程度 |
| 容忍度 | 民众对风险的容忍临界点 |
| 风险度 | 项目本身的风险程度 |

### 风险识别四步法
1. 大数据预识别 — 基于历史数据进行风险预判和分类分级
2. 虚拟空间识别 — 网民意见调查，分析网络舆情中的风险信号
3. 现场实地识别 — 现场告知与态度调查
4. 全监测动态识别 — 建立动态"风险点清单"，持续跟踪

### 风险分析三维框架
- "客观—主观"分析：概率—损失分析、最好—最坏可能性分析
- "内部—外部"分析：利益相关分析、责任—影响分析
- "静态—动态"分析：连锁反应分析、风险升级预测

### 风险定级三种方法
1. 对照排查定级法 — 同类案例分析对比
2. 定量计算定级法 — 精确计量风险
3. 综合研判定级法 — 研判"反对度—承受力"状况

## 二、全方位评估框架（李开孟《重大工程社会稳定风险分析和评估咨询专业指南》）

### 评估报告核心章节
1. 评估工作的组织实施
2. 风险调查评估及各方意见采纳情况
3. 风险识别和估计的评估
4. 风险防范和化解措施的评估
5. 落实措施后的风险等级确定
6. 评估结论（主要风险因素、四性评估结论、风险等级、防范化解措施、应急预案建议）

### "以问题解决为导向"的稳评分析框架
- 不是简单地评判风险等级，而是推动问题解决
- 评估报告要明确：谁负责解决什么问题、什么时间完成
- 风险应对措施要具体到责任主体、协助单位、时间节点

### 风险应对行动计划
- 项目生命周期各阶段（决策、准备、实施、运行）的应对措施
- 应急预案编制方法
- 风险监测和动态调整机制

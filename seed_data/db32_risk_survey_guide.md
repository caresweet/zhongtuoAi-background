# DB32/T 4013-2021 江苏省稳评规范 — 风险调查与样本量标准

> **【技术标准/江苏省/2021/风险调查章节/样本量不足风险、调查覆盖不全风险】**

## 风险调查范围与方法

风险调查围绕合法性、合理性、可行性、可控性四个维度展开。

### 调查方式
- 公示公告（时间不少于7个工作日）
- 问卷调查（按样本量标准执行）
- 实地走访与踏勘
- 座谈会、听证会
- 网络舆情分析
- 专家咨询

## 各类项目调查样本量标准

| 项目类型 | 利益相关者规模 | 最低调查比例/数量 |
|----------|---------------|-------------------|
| 征地拆迁项目 | 全部直接利益群体 | 100%（所有被征地拆迁户及企事业单位） |
| 涉环保项目(3km) | 居民不足100户 | >90% |
| 涉环保项目(3km) | 100~500户 | >50%且不低于90户 |
| 涉环保项目(3km) | 超过500户 | >30%且不低于250户 |
| 邻避项目(4km) | 居民不足100户 | >95% |
| 邻避项目(4km) | 100~500户 | >60%且不低于95户 |
| 邻避项目(4km) | 超过500户 | >40%且不低于300户 |
| 企业改制事项 | 不足100人 | >90% |
| 企业改制事项 | 100~500人 | >50%且不低于90人 |
| 企业改制事项 | 超过500人 | >30%且不低于250人 |
| 重大政策出台 | 直接利益群体 | 不少于200份 |
| 重大政策出台 | 间接利益群体 | 不少于100份 |

## 风险等级判定

### 方式一：直接定性指标
| 情形 | 等级 |
|------|------|
| 超过50%以上群众反对 | 高风险 |
| 可能引发200人以上群体性事件 | 高风险 |
| 可能引发恶性案件 | 高风险 |
| 可能引发个人极端事件 | 高风险 |
| 20%以上~50%以下群众反对 | 中风险 |
| 可能引发100人以上群体性事件 | 中风险 |

### 方式二：量化指标评价体系
稳评总分W = A+B+C+D+E+……+T+U
- W ≥ 70 → 高风险
- 40 < W < 70 → 中风险  
- W ≤ 40 → 低风险

## 三种评估程序
1. 简易程序：技改项目、公益性民生项目、预判无明显风险隐患事项（不适用于征地、拆迁等）
2. 一般程序：完整流程（公示→调查→评估→评审→备案），适用于大多数决策事项
3. 特别程序：涉及群众人数众多、利益矛盾尖锐、存在重大风险的事项

# 社会稳定风险评估报告撰写指南

> **【工作指南/淮安市/通用/第十章全流程/补偿争议风险、程序风险、舆情风险】**

## 第一章 拟征收决策基本概况

决策名称应写明征收项目全称及文号，格式为"XX拟征告〔20XX〕X号"。
征收主体依据《中华人民共和国土地管理法》第四十六条，必须是县级以上地方人民政府。
稳评责任单位为具体负责组织实施征地社会稳定风险评估的政府部门。
稳评实施单位为受委托承担评估技术服务的社会稳定风险评估机构。
项目基本情况包括：拟征收土地位置（从省到村组逐级写明）、四至范围、总面积（㎡和亩）、地类构成（农用地/建设用地/未利用地）、地上附着物、土地用途。
征收补偿标准按照江苏省人民政府公布的征地区片综合地价执行，补偿内容包括土地补偿费、安置补助费、地上附着物和青苗补偿费。
安置方式以货币补偿为主、社会保障安置为辅，被征地农民纳入城乡居民基本养老保险体系。

## 第二章 评估过程、方法和依据

评估过程六步：制定方案→收集资料→实地调查→风险识别→风险分析→报告编制。
评估方法五种：资料收集法（收集法律法规、政策文件、规划资料、项目文件）、问卷调查法（发放问卷、统计有效样本、分析支持率）、座谈访谈法（村组干部座谈会、群众代表座谈会、利益相关者座谈会、个别访谈）、现场勘查法（实地踏勘、拍摄现场照片）、舆情分析法（监测网络舆情、分析群众关注热点）。
评估依据四类：国家法律（《土地管理法》2019年修正、《突发事件应对法》2024年修订、《国有土地上房屋征收与补偿条例》）、地方性法规与政府规章（《江苏省征地补偿和被征地农民社会保障办法》）、技术标准与规范（DB32/T4013-2021《第三方社会稳定风险评估规范》、国家发展改革委《重大固定资产投资项目社会稳定风险评估暂行办法》）、规划与项目文件（城市总体规划、土地利用总体规划、征收土地预公告、勘测定界报告）。

## 第三章 社会稳定风险因素调查

调查方法：问卷调查、座谈访谈、现场勘查、舆情分析相结合。
问卷调查：发放问卷覆盖被征地社区，统计有效回收率、项目知晓度、项目支持度。
群众主要关切：补偿标准（占比最高）、安置方式、社会保障、信息公开。
利益相关者分类：被征地农户（核心诉求：合理补偿+妥善安置）、村集体组织（核心诉求：集体经济可持续发展）、其他利益相关者（土地承包经营权人、地上附着物所有权人等）。

## 第四章 决策综合分析

合法性分析四维度：
1. 决策主体资格合法性 — 依据《土地管理法》第46条，征收主体必须是县级以上地方人民政府
2. 决策目的合法性 — 依据《土地管理法》第45条，符合公共利益需要的情形
3. 规划相符性 — 符合国土空间规划、土地利用总体规划、城乡规划
4. 程序合规性 — 履行征收预公告（≥10个工作日）、土地现状调查、社会稳定风险评估、补偿方案公告（≥30日）、听证会（如需）

合理性分析三维度：
1. 区域经济社会发展合理性 — 项目对产业布局、城市功能的促进作用
2. 补偿方案公平性 — 执行区片综合地价，与周边项目比较
3. 群众利益保障 — 落实"原有生活水平不降低、长远生计有保障"（《土地管理法》第48条）

可行性分析三维度：
1. 资金保障可行性 — 纳入财政预算，资金到位
2. 实施条件可行性 — 基础设施配套、施工条件
3. 群众接受度可行性 — 问卷调查支持率、利益相关者态度

可控性分析四维度：
1. 安全风险可控性 — 社会治安状况、历史遗留问题
2. 舆情风险可控性 — 政策宣传、舆情监测机制
3. 群体性事件风险可控性 — 历史信访情况、矛盾排查化解
4. 整体可控性 — 综合研判

## 第五章 风险因素识别与初始等级表

征地类项目主要风险因素：
1. 补偿标准争议 — 群众期望值高于政策标准，风险等级：中
2. 安置方式不满 — 对货币补偿方式存在疑虑，风险等级：低
3. 社会保障问题 — 对征地后社保政策不了解，风险等级：低
4. 施工环境影响 — 噪音扬尘影响周边生活，风险等级：低
5. 补偿资金发放风险 — 资金不能及时足额到位，风险等级：中
6. 信息公开不充分 — 程序透明度不足引发猜疑，风险等级：低

## 第六章 措施前风险等级研判

按照DB32/T4013-2021量化评分指标体系，从合法性、合理性、可行性、可控性四个维度逐项打分。
合法性指标得分较高（征收主体、目的、程序均合规）。
合理性指标基本合理（补偿方案按区片综合地价执行）。
可行性指标较可行（资金保障、施工条件、群众支持度）。
可控性指标整体可控（风险因素已识别、已制定防范措施）。
措施前综合得分通常为80-90分，判定为低风险（A级）。

## 第七章 风险防范与化解措施

八大防范措施：
1. 加强政策宣传与信息公开 — 制作宣传手册、组织政策解读会、公示征收信息
2. 严格依法履行征收程序 — 逐一落实预公告、现状调查、方案公告、听证等环节
3. 完善补偿方案保障群众权益 — 合理确定补偿标准、落实社保政策
4. 确保补偿资金及时足额发放 — 设立资金专户、专款专用
5. 畅通群众沟通渠道 — 设立信访窗口和咨询电话、一对一沟通
6. 加强舆情监测与应对 — 建立日常监测机制、官方渠道发布权威信息
7. 制定维稳应急处置预案 — 成立应急小组、制定群体性事件处置预案
8. 落实后续跟踪与效果评估 — 定期"回头看"、评估措施效果

## 第八章 措施后风险等级评估

在全面落实风险防范化解措施后重新评估：
1. 补偿方案优化 → 群众满意度提升
2. 政策宣传到位 → 群众知晓度提高至95%以上
3. 信访渠道畅通 → 群众诉求得到及时回应
4. 舆情监测到位 → 及时发现处置负面信息
措施后综合得分通常高于措施前5-10分，判定为低风险（A级）。

## 第九章 评估结论与建议

评估结论格式：经综合评估，XX项目决策社会稳定风险等级为XX级。从合法性、合理性、可行性、可控性四个维度分别给出结论。综合研判：建议在措施落实后予以实施。

工作建议五条：
1. 严格执行征收补偿政策
2. 加强被征地农民的就业帮扶和社会保障
3. 做好施工期间的群众工作
4. 建立风险监测预警和应急处置机制
5. 落实跟踪评估和"回头看"制度

## 第十章 应急预案

组织指挥体系：成立征地稳评应急工作领导小组，由责任单位负责人任组长，相关部门负责人为成员。
分级响应：一般事件（Ⅳ级）由乡镇街道处置，较大事件（Ⅲ级）由县级处置，重大事件（Ⅱ级及以上）报请市级。
处置措施：群体性事件迅速组织公安力量控制现场，恶性事件启动公安应急机制，网络舆情事件启动舆情应急预案，信访事件按信访工作条例及时受理妥善处理。
